# Abbreviazioni da tastiera
<!-- description: Accorda senza mouse. -->

| Azione | Abbreviazione |
| :-- | :-- |
| Avviare o fermare l'ascolto | Comando-L |
| Riconoscere la corda automaticamente | Comando-0 |
| Accordare la corda da 1 a 6 | Da Comando-1 a Comando-6 |
| Nuova finestra accordatore | Comando-N |
| Impostazioni | Comando-virgola |
| Chiudere la finestra | Comando-W |
| Uscire da ChitarraTune | Comando-Q |

Con Accesso completo da tastiera attivo in Impostazioni di Sistema > Accessibilità > Tastiera, premi Tab per spostarti tra i controlli e la barra spaziatrice per premere quello selezionato.

**Su iPad con una tastiera:** funzionano le stesse abbreviazioni. Tieni premuto Comando per vederle.
