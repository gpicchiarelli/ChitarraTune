# Cambiare l'accordatura
<!-- description: Scegli una delle dieci accordature per chitarra. -->

Fai clic sul menu dell'accordatura sotto l'indicatore, che mostra l'accordatura attuale, poi scegline una. Puoi sceglierla anche dal menu Accordatura nella barra dei menu.

| Accordatura | Corde, dalla più grave alla più acuta |
| :-- | :-- |
| Standard | Mi La Re Sol Si Mi |
| Mezzo tono sotto | Mi♭ La♭ Re♭ Sol♭ Si♭ Mi♭ |
| Un tono sotto | Re Sol Do Fa La Re |
| Drop D | Re La Re Sol Si Mi |
| Drop C | Do Sol Do Fa La Re |
| DADGAD | Re La Re Sol La Re |
| Open D | Re La Re Fa♯ La Re |
| Open G | Re Sol Re Sol Si Re |
| Open E | Mi Si Mi Sol♯ Si Mi |
| Open A | Mi La Mi La Do♯ Mi |

ChitarraTune ricorda l'ultima accordatura usata. Sul Mac, ogni finestra dell'accordatore ha la sua accordatura; consulta [Usare più di un accordatore](windows.md).

**Su iPhone o iPad:** tocca il menu dell'accordatura sotto l'indicatore.
