# Use Siri, Shortcuts and controls
<!-- description: Start and stop tuning by voice, from a shortcut, from Control Center or the menu bar. -->

## Siri

Say, for example:

- "Start tuning in ChitarraTune"
- "Stop tuning in ChitarraTune"
- "Set tuning in ChitarraTune"

ChitarraTune opens when it starts listening, because the microphone can be used only by an app in front.

## Shortcuts

In the Shortcuts app, ChitarraTune offers these actions:

| Action | What it does |
| :-- | :-- |
| **Start Tuning** | Opens ChitarraTune and starts listening. |
| **Stop Tuning** | Stops listening. |
| **Set Tuning** | Chooses one of the ten tunings. |
| **Set Reference Pitch** | Sets A4, from 415 to 466 Hz. |
| **Pick String** | Chooses string 1 to 6, or automatic detection. |
| **Choose Microphone** | Chooses the input. |

## Control Center and the menu bar

Add the **Start Tuning** control to Control Center or to the menu bar on your Mac; on iPhone and iPad also to the Lock Screen or the Action button. Clicking or tapping it opens ChitarraTune and starts listening.
