# Read the tuner
<!-- description: What the note, the cents, the needle and the colors mean. -->

While ChitarraTune listens, the window shows:

| Item | What it tells you |
| :-- | :-- |
| Note | The string ChitarraTune hears, with its octave, for example E2. |
| Hz | The frequency it measures, in hertz. |
| Cents | How far the string is from its pitch. A semitone is 100 cents; −12 means 12 cents too low. |
| Needle or bar | The same distance, drawn on a scale from −50 to +50 cents. The green zone is ±5 cents. |
| Status | **Flat** (too low), **Sharp** (too high), **Almost there** (within 15 cents) or **In tune**. |
| Level | The thin bar under the gauge shows that the microphone hears you. |

**In tune** appears only once the string has stayed within 5 cents of its pitch for a moment, and stays until the string drifts more than 7 cents away, so the display does not flicker while you adjust the peg.

When the string stops ringing, the last reading stays on screen, dimmed, for a moment, so you can still read it.

> **Tip:** Colors are never the only signal: each state also has its own word and symbol.

To change between the dial and the bar, or the way note names are written, see [Change ChitarraTune settings](settings.md).
