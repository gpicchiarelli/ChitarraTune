# Keyboard shortcuts
<!-- description: Tune without the mouse. -->

| Action | Shortcut |
| :-- | :-- |
| Start or stop listening | Command-L |
| Detect the string automatically | Command-0 |
| Tune string 1 to 6 | Command-1 to Command-6 |
| New tuner window | Command-N |
| Settings | Command-Comma |
| Close the window | Command-W |
| Quit ChitarraTune | Command-Q |

With Full Keyboard Access turned on in System Settings > Accessibility > Keyboard, press Tab to move between controls and Space to press the selected one.

**On iPad with a keyboard:** The same shortcuts work. Hold down Command to see them.
