# Get an accurate reading
<!-- description: Tips for a steady, precise reading. -->

ChitarraTune measures the pitch of the string itself, to within a fraction of a cent. These habits help it hear the string clearly:

- **Play one string at a time,** and mute the others with your hand: ChitarraTune tunes one string at a time and does not analyze chords.
- **Let the string ring.** The reading settles within a moment of the pluck; **In tune** appears once it has stayed within 5 cents.
- **Pluck normally,** away from the bridge. Very soft plucks close to the bridge are the hardest to measure.
- **Stay close to the microphone,** or plug the guitar into an audio interface. ChitarraTune adapts to a quiet room and hears soft sources, such as an amplifier at low volume, without raising the input gain.
- **Tune up to the note.** If a string is sharp, bring it below the note and tune up to it: the string then holds its pitch better.
- **If a string is far out of tune,** choose it below the gauge so ChitarraTune listens only for it. See [Tune one string at a time](pin-string.md).
