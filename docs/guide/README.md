For contributors: every page exists in both languages, with the same file name. `Scripts/build-help.py` turns them into the Mac's Help Book, `Help/ChitarraTune.help`; a test fails if the book and these pages differ. Keep to the Markdown the script understands (headings, paragraphs, bold, lists, numbered steps, tables, "> " notes), name interface elements exactly as the app does, and link pages by their `.md` file name.
