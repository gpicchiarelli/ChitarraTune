Tune one string at a time

ChitarraTune normally recognizes which string you play. When a string is far out of tune, or other strings ring along, choose the string yourself: ChitarraTune then listens only around that string's pitch.

  • Choose a string: Click the string below the gauge, for example E2. The display suggests which string to play.

  • Go back to automatic detection: Click Auto.

You can also choose Tuning > String 1 through String 6, or press Command-1 through Command-6. Command-0 returns to automatic detection.

On iPhone or iPad: Tap the string, or tap Auto.

Strings are numbered from the lowest, string 1, to the highest.
