Accessibility features

  • VoiceOver reads the note as words, for example "E flat, octave 2", with how far it is from pitch, and announces when a string is in tune. The gauge and the note are each a single element, so VoiceOver does not repeat itself while the reading changes.

  • Larger text: the text grows with the size you choose in System Settings, up to the largest accessibility sizes; when it no longer fits, the window scrolls.

  • Reduce Motion: the needle and the colors change without animation.

  • Increase Contrast and Differentiate Without Color: the colors switch to higher-contrast versions, and every state also has its own word and symbol.

  • Voice Control: every button has a name you can say, for example "Click Start Listening" or "Click Auto".

  • Keyboard: every action has a shortcut; see Keyboard shortcuts.

On iPhone or iPad: A soft tap confirms when a string is in tune; you can turn it off in Settings, Haptics.
